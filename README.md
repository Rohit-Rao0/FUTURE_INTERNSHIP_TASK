### Task 2: VedacureMe – Hospital Management System

A web-based hospital management application designed to support doctor discovery, patient registration, and appointment management.

**Technologies:** React.js, Node.js, Express.js, MongoDB, Mongoose

**Features:**
- Role selection for Admin, Doctor, and Patient
- User login and registration
- Doctor search by name or specialization
- Appointment booking
- Patient appointment management
- Doctor availability and appointment management
- Admin management of doctors, patients, and appointments

**Folder:** `Task-2-Mini-CRM/`

## 🚀 Getting Started

Each project has its own source code and setup requirements.

1. Clone this repository:

   ```bash
   git clone https://github.com/Rohit-Rao0/FUTURE_FS_01.git
   ```

2. Open the folder of the project you want to run.
3. Follow its README and installation instructions.
4. Install the required dependencies.
5. Configure environment variables where required.
6. Start the application using the commands specified in that project's README.

## 🔐 Security

- Environment files containing secrets are excluded from version control.
- Dependencies should be installed using the project's package files.
- Never publish database credentials, passwords, or secret keys.
